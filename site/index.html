Compose, compile, run

A song is typed data; compiling it is a pure function; the Program is the artifact.

Compose

Tracks from 31 catalog instruments, patterns on a bar grid, tempo and time-signature maps, beat-addressed automation, buses and sends — one typed Song in Rust or Python.

Compile

song.compile() validates everything and emits a hashed Program: resolved document, metadata, resource estimates. One canonical hash — identical from Rust or Python, on any OS. program 1 · schema 2 · engine 5

Render offline

render() the full mix, render_range(bars=…) a slice, render_stems() every track and bus. Same input, same bytes — test it, diff it, cache it.

Run live

Performance plays the Program with sample-accurate scheduling: a command queue, bar-quantized transitions, crossfaded swaps, stingers on the downbeat. Musical timing is the engine's job, never your loop's.

Write a song

The whole flow in one Python session — the same song compiles from Rust with the same hash.

import tono

song = tono.Song("night-drive", tempo=122, seed=7)
drums = song.track("drums", tono.instruments.drums("tr808"))
bass = song.track("bass", tono.instruments.bass("finger"))

beat = tono.Pattern(bars=1)
beat.hit("kick", beats=[0, 2])
beat.hit("snare", beats=[1, 3])
riff = tono.Pattern(bars=1)
riff.notes(["C2", "C2", "Eb2", "G2"], durations=0.5)

song.arrange(drums, beat, bars=range(8))
song.arrange(bass, riff, bars=range(0, 8, 2))
song.automate(bass, "gain", [(0, 0.2), (8, 0.9)], curve="exp")

program = song.compile(sample_rate=48_000)
mix = program.render()                      # stereo float32 (frames, 2)
stems = program.render_stems()              # every track + bus, separate
outro = program.render_range(bars=(6, 8))   # a slice of the mix

Live, the same Program runs under tono.Performance — perf.play(), then perf.transition("chorus", at=tono.next_bar()) lands exactly on the bar. No code at all? The CLI renders any sound doc: tono render doc.json -o out/ → audio + spectrogram + waveform + LUFS stats.

Get started

Two commands to the first render; the loop is: write a doc, render, look, refine.

# the CLI
cargo install tono
tono render blip.json -o out/   # → wav + spectrogram + waveform + LUFS stats

# the engine, in a game or tool
cargo add tono-core
